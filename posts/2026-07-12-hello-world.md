# Hello World!

Welcome to **Block Blog** — a blog about coding, crypto, and building things that matter.

## What to Expect

This blog will cover topics like:

- **Software development** — React, TypeScript, and full-stack patterns
- **Crypto & blockchain** — Bitcoin Cash, tokenization, and decentralized apps
- **Automation** — AI agents, CI/CD, and developer tooling
- **Lessons learned** — Mistakes, discoveries, and hard-won wisdom

## How This Blog Works

This blog is built with:

- [Vite](https://vite.dev) + [React](https://react.dev) for the frontend
- [react-bootstrap](https://react-bootstrap.github.io) for styling
- [react-markdown](https://github.com/remarkjs/react-markdown) to render posts
- [gray-matter](https://github.com/jonschlinkert/gray-matter) for frontmatter parsing

All posts are plain markdown files stored in the repository. When changes are pushed to `main`, a GitHub Actions workflow automatically builds and deploys the site to GitHub Pages.
